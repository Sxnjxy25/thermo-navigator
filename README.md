# ThermoAnalyzer Pro

Advanced Thermodynamics & Heat System Calculator built with React, TypeScript, Vite, and Tailwind CSS.

## Getting Started

### Prerequisites

Ensure you have Node.js (v18 or higher) and npm installed.

### Installation & Running Locally

1. Install dependencies:
```sh
npm install
```

2. Start development server:
```sh
npm run dev
```

3. Build for production:
```sh
npm run build
```

4. Run tests:
```sh
npm test
```

## Technologies Used

- **Framework / Build Tool**: Vite, React, TypeScript
- **UI & Styling**: Tailwind CSS, Shadcn UI, Lucide Icons
- **State & Data Handling**: React Hooks, Recharts, TanStack Query
